# DemoHarness 首版能力

首版面向单个使用者在本机学习和运行 Agent，支持选择多个相互隔离的 Agent。Python API 与 CLI 共享一个异步运行时和 SQLite。进程退出时暂停任务，启动后核对并继续安全的步骤。

| 能力 | 可运行的范围 |
|---|---|
| Agent | 自己的目录、身份与规则、项目及长期记忆。交互协调和任务执行分工。 |
| Task 与 Session | 每件事有一个 Task、一个业务 Session 和一个工作副本。可并行推进不同 Task，歧义时澄清，明确相关跟进继续原 Task。 |
| 动态 Plan | 有序步骤带稳定 ID、状态和证据引用。任务执行者可按新信息修订，记录原因。完成取决于实际验收。 |
| 工具与约束 | 在副本内读取、写入普通文件并运行类型化检查。Git 优先使用独立 worktree。文件和模型调用有预算、取消与授权检查。 |
| 验证与纠正 | 文件存在、内容和静态 Python 语法等检查。失败反馈到有限纠正。通过后保存验收证据和差异。 |
| 中断恢复与压缩 | 持久记录输入、Run、工具意图和结果。对账后继续安全操作，未知副作用等待。原始历史保留，模型 Context 可压缩。 |
| 临时子 Agent | 同一 Task 内的独立上下文，可按需查询父 Session。只读调查并回传结论和证据，沿用父预算和停止信号。 |
| Agent 长期记忆 | 从可验证的 Task 记录提炼，支持显式记住、候选、相关召回、更正、失效和删除。 |
| 主动发现 | 默认观察源仓库提交。协调器自主判断是否创建工作，重复来源及已知工作关联既有记录。 |
| 模型和入口 | OpenAI 兼容 Chat Completions，可注入确定性模型。Python API 与前台 CLI。 |

首版面向工作副本交付差异。成果的合入、推送、发布由用户另行处理。任意仓库脚本需要经过验证的进程隔离后端。会话树、Web、多人协作及跨 Agent 自动派单留待后续讨论。旧库可以原样保留，新状态写入 `agent.sqlite3`。
